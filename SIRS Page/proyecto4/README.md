# Proyecto 4 - Automatización RPA

## Contenido
- `index.html`: landing local y redirección.
- `demo.html`: panel de monitoreo RPA.
- `assets/`: carpeta lista para íconos o capturas.

## Uso local
Abrir `index.html` o `demo.html?mode=demo` directamente.

## Demo mode
Se persiste en `localStorage` con la clave `sirs-proyecto4-mode`.

## Publicación
1. Copiar la carpeta `proyecto4/` al hosting estático.
2. Mantener la estructura actual.
3. No requiere compilación.
