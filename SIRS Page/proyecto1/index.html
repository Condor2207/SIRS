✦ Funcionalidades

📊
Dashboard en tiempo real — KPIs de ventas, ganancias, transacciones y alertas de stock bajo.
💰
Punto de Venta (POS) — Registro de ventas, carrito de compra, factura automática y múltiples métodos de pago.
🏦
Control de Caja — Apertura y cierre de caja diaria con saldo inicial y cierre con resumen.
📋
Inventario — Lista de productos con alertas de stock mínimo y control de reabastecimiento.
📈
Reportes — Reportes de ventas por período, productos más vendidos y rentabilidad.
📦
Gestión de Productos — Alta, baja y modificación de productos con categorías y precios.
🚚
Proveedores — Registro y administración de proveedores vinculados a productos.
🔒
Autenticación con roles — JWT con roles Admin y Vendedor; permisos diferenciados por módulo.
