🛒 SuperStock Demo

Sistema de gestión para supermercados: ventas, inventario, caja, proveedores y reportes gerenciales en una sola plataforma.

FastAPI SQLAlchemy JWT Auth HTML · CSS · JS SQLite Chile · CLP

¿Qué hace este sistema?

📦 Módulos Principales

  • ✓ Dashboard ejecutivo con KPIs en tiempo real
  • ✓ Punto de Venta (POS) con emisión de facturas
  • ✓ Control de inventario y alertas de stock bajo
  • ✓ Gestión de proveedores y órdenes de compra
  • ✓ Apertura y cierre de caja diaria
  • ✓ Reportes de ventas y ganancias por período

⚙ Características Técnicas

  • ✓ API REST con FastAPI + documentación automática
  • ✓ Autenticación segura con JWT Bearer tokens
  • ✓ Roles diferenciados: Administrador y Vendedor
  • ✓ Interfaz con modo claro y oscuro (Light / Dark)
  • ✓ Diseño responsive para escritorio y móvil
  • ✓ Base de datos relacional con SQLAlchemy ORM
