SGS — Sistema de Gestion para Supermercados

Plataforma integral de gestion comercial para supermercados: punto de venta (POS), control de inventario, ordenes de compra, caja diaria y reportes de negocio. Desarrollado para el mercado paraguayo, opera en Guaranies (PYG).

Paraguay PYG POS Inventario Reportes

Caracteristicas principales de la demo:

  • Dashboard ejecutivo con KPIs del dia: ventas, productos, caja y alertas.
  • Punto de venta (POS) con carrito interactivo y comprobante de venta.
  • Control de inventario con alertas de stock minimo por proveedor.
  • Modulo de compras con reabastecimiento sugerido agrupado por proveedor.
  • Reportes de ventas y compras exportables a Excel y PDF.
  • Gestion de caja: apertura, cierre y diferencia de efectivo.
  • Roles de usuario: admin y vendedor con accesos diferenciados.
  • Moneda en Guaranies, sin decimales, formato local paraguayo.

Stack tecnologico:

Python 3 · FastAPI SQLAlchemy · SQLite JWT Auth · PBKDF2 HTML5 · CSS3 Vanilla JS SheetJS · jsPDF
