# Proyecto 2 - ERP Constructora Uruguay

## Contenido
- `index.html`: landing local con redirección.
- `demo.html`: dashboard funcional con datos de prueba.
- `assets/`: carpeta reservada para recursos.

## Ejecución local
Abrir `index.html` o `demo.html?mode=demo` directamente en el navegador.

## Demo mode
El dashboard guarda el modo demo en `localStorage` con la clave `sirs-proyecto2-mode`.

## Deployment estático
1. Publicar la carpeta `proyecto2/` completa.
2. Mantener rutas relativas.
3. No requiere backend para la demo.

## Funciones incluidas
- Contadores animados.
- Simulación cada 5 segundos.
- Exportación de CSV.
