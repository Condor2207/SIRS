# Proyecto 5 - Power BI Embed Simulado

## Contenido
- `index.html`: landing local con redirección.
- `demo.html`: reporte ejecutivo simulado.
- `assets/`: carpeta disponible para imágenes o branding.

## Uso local
Abrir `index.html` o `demo.html?mode=demo` en el navegador.

## Modo demo
La bandera demo se persiste en `localStorage` con la clave `sirs-proyecto5-mode`.

## Deployment estático
1. Publicar la carpeta `proyecto5/` completa.
2. No requiere backend ni servidor de aplicaciones.
3. Compatible con cualquier hosting estático.
