```

#### 4A.2 Cambia placeholders uno a uno
```

6. Pasa al siguiente placeholder

## 🆘 SI ALGO FALLA

### Página no se abre
```
Solución:
1. Verifica la ruta en navegador:
   file:///e:/Sistemas/SIRS Page/index.html
2. Revisa que está escrito exactamente igual
3. Intenta con navegador diferente
```

### Cambios no se ven
```
Solución:
1. Guarda el archivo (Ctrl+S)
2. Recarga la página (F5)
3. Si no funciona: Ctrl+Shift+R (caché limpio)
```

### Imágenes no cargan
```
Solución:
1. Verifica que la imagen está en carpeta "imagenes"
2. Revisa el nombre exacto (mayúsculas/minúsculas)
3. El path debe ser: imagenes/nombre.jpg
```
