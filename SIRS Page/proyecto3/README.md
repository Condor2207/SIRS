# Proyecto 3 - CRM Ventas México

## Contenido
- `index.html`: landing local con CTA y redirección.
- `demo.html`: dashboard CRM funcional.
- `assets/`: reservado para recursos.

## Ejecución local
Abrir `index.html` o `demo.html?mode=demo` en el navegador con `file://`.

## Modo demo
Se detecta `?mode=demo` y se persiste en `localStorage` con la clave `sirs-proyecto3-mode`.

## Deployment
1. Publicar la carpeta `proyecto3/` completa.
2. No requiere proceso de build.
3. Compatible con hosting estático.

## Extras
- Exportación CSV desde navegador.
- Simulación de tiempo real cada 5 segundos.
