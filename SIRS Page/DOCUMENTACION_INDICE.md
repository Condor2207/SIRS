## 🎓 MINI TUTORIALES

### Tutorial 1: Cambiar nombre empresa (3 min)
1. Abre `index.html` en VS Code
2. Ctrl+H
3. Find: `[NOMBRE_EMPRESA]`
4. Replace: `Tech Solutions`
5. Replace All
6. Guardar (Ctrl+S)
7. Recargar navegador

### Tutorial 2: Cambiar color primario (2 min)
1. Abre `style.css`
2. Ctrl+F: `--color-primary`
3. Ir a línea 7
4. Cambiar: `#0066cc` a tu color (ej: `#ff0000`)
5. Guardar (Ctrl+S)
6. Recargar navegador (F5)

### Tutorial 3: Agregar imagen perfil (5 min)
1. Copia tu imagen a: `e:/Sistemas/SIRS Page/img/perfil.jpg`
2. Abre `index.html`
3. Busca: `<div class="placeholder-circle"`
4. Reemplaza con: `<img src="img/perfil.jpg" alt="Perfil">`
5. Guardar y recargar
